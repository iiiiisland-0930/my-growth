# C++ 学习练习

这是一个用于保存 C++ 入门学习和练习代码的仓库，当前包含数组排序、字符串处理等基础示例。

## 文件说明

| 文件 | 内容 |
|---|---|
| `array.cpp` | 读取一组整数，进行排序、计算平均值，并将平均值加入数组后输出 |
| `1104ojhw.cpp` | 读取多个字符串，并尝试按字符串首字母排序后输出 |
| `1104string.cpp` | 将输入字符串中的英文字母大小写互换，并过滤数字 |

## 编译与运行

需要安装支持 C++ 的编译器，例如 g++。

以 `array.cpp` 为例：

```bash
g++ array.cpp -o array
./array
```

编译其他文件时，将文件名和生成的程序名替换即可。

## 说明

这些代码主要用于学习和练习 C++ 基础语法与常见操作。部分程序可能依赖特定编译器（例如使用了 Visual C++ 的 `strcpy_s`），在其他编译环境中可能需要适当调整。
